# 生财航海手册整理 Skill（非官方）

把你本人已经购买，或以其他合法方式取得访问权限的生财航海手册页面中的 `Plain Text` 区块，整理成一套能够顺着阅读、持续更新的本地 Markdown 笔记。

> **非官方声明**
>
> 本项目为个人独立开发的本地整理工具，与生财有术及其关联主体不存在隶属、合作、授权或背书关系。
>
> 本项目不包含、托管或分发任何课程正文、图片、音视频、账号凭据或访问令牌，也不会绕过登录、付费、验证码或其他访问控制。
>
> 使用者只能处理本人已经取得访问权限的内容，并应遵守相关平台协议、著作权规则和内容授权范围。通过本项目生成的课程笔记不应被再次公开传播、出售或用于替代原课程。

## 它解决什么问题

把提示词复制下来并不难，真正麻烦的是整理之后仍然不知道前后关系。

这个 Skill 会根据手册原本的目录和正文，把提示词恢复成一套可以顺着执行的流程：

- 一本手册建立一个文件夹；
- 一个关卡或章节建立一篇笔记；
- 只收集页面明确标记为 `Plain Text` 的区块；
- 根据同一手册原文，在提示词前组织承上启下的说明；
- 主流程、互斥分支、参考示例和异常路径分别标清；
- 首次整理和后续增量更新使用同一套结构；
- 写入前先列出“新增、需要更新、保持不动、本地保留”；
- 只有用户确认后才写入本地文件。

最终不会再给每条提示词单独添加“用途”和“何时使用”。说明会直接交代上一步完成了什么、这一步为什么要做，以及完成后进入哪里。

## 取数方式

Skill 会根据当前环境选择可用的只读方式：

1. 已连接 `scys-mcp` 时，优先读取手册目录和正文结构；
2. 没有连接器时，回退到用户已经登录的网页；
3. 网页模式优先读取 DOM 和同源 iframe；
4. DOM 无法取得原文时，才使用 Plain Text 区块自己的复制或下载能力。

两种方式都不会读取或导出 Cookie、Token、密码和浏览器配置，也不会使用站内搜索、网络缓存或第三方镜像补齐内容。

## 输出结构

```text
手册标题/
├── 00-手册总览与SOP.md
├── 01-第一关或第一章.md
├── 02-第二关或第二章.md
└── ...
```

支持两种输出：

- Obsidian Vault：使用 `[[双向链接]]` 组织导航；
- 普通 Markdown：使用相对链接组织导航。

输出默认写到用户自己选择的本地目录，不应写进本 Skill 仓库。

## 安装

在支持本地 Skills 的 Codex 环境中，可以把本仓库克隆到个人 Skills 目录：

```bash
git clone https://github.com/shiqi-dza/17-scys-manual-collector.git ~/.codex/skills/17-scys-manual-collector
```

重新打开 Codex 后，可以通过 `$17-scys-manual-collector` 显式调用。不同宿主的 Skills 安装目录可能不同，请以对应宿主的说明为准。

## 使用

可以直接告诉 Codex：

```text
使用 $17-scys-manual-collector 整理我有权访问的这份生财航海手册。
输出到我的 Obsidian，并先预览新增、需要更新和保持不动的笔记，不要直接覆盖。
```

执行前需要准备：

- 本人已经取得访问权限的手册链接或名称；
- 已连接的 `scys-mcp`，或者已经登录手册网站的浏览器；
- Obsidian Vault 或普通 Markdown 的真实输出目录；
- 首次收集或更新现有手册的选择。

## 增量更新

Skill 不会直接覆盖现有笔记。每次写入前都会生成候选文件，并把差异分成四类：

| 状态 | 处理方式 |
| --- | --- |
| 新增 | 等待用户确认后创建 |
| 需要更新 | 展示变化摘要，等待用户确认 |
| 保持不动 | 内容一致，不写入 |
| 本地保留 | 网页计划中没有，不自动删除 |

用户可以只确认其中一部分文件。

## 项目边界

本项目支持：

- 整理本人有权访问的手册页面；
- 只提取 `Plain Text` 区块；
- 在用户自己的设备上生成本地 Markdown；
- 在用户确认后进行增量更新；
- 对输出做结构、链接和脱敏检查。

本项目不支持：

- 绕过登录、购买、权限、验证码或其他访问控制；
- 获取用户没有访问权限的内容；
- 下载、镜像或搬运完整课程；
- 将课程提示词合集、截图或整理结果公开传播或出售；
- 把 Cookie、Token、密码或签名链接写入命令、日志或输出；
- 代替用户购买原课程，或证明某种使用方式已经获得权利人授权。

## 验证

Skill 结构可以使用 Codex 自带的 Skill 校验脚本检查。生成的手册目录可以运行：

```bash
python3 scripts/validate_output.py <手册文件夹> --mode <obsidian|markdown> --expected-plain-text <数量>
```

这个脚本检查目录结构、Plain Text 数量、链接、禁止字段和常见隐私泄漏。承上启下说明是否忠于课程原文，仍需与用户有权访问的原页面进行核对。
