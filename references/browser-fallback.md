# 已登录网页回退模式

此模式只在 scys-mcp 手册目录或正文能力不可调用时使用。目标是读取用户已经有权限查看的页面，不绕过任何访问控制。

开始前确认用户已经购买或以其他合法方式取得目标手册的访问权限。登录成功只证明当前会话能够打开页面，不能扩大用户对内容的复制、传播或商业使用权限。

## 选择浏览器

遵守当前主机的浏览器 Skill / 工具说明。用户明确指定内置浏览器、Chrome 或其他浏览器时使用该表面；否则优先复用已经登录并打开目标网站的浏览器。

不要读取 Cookie、localStorage、Token、密码、浏览器配置或历史记录。登录阻塞时请用户接管登录，完成后再继续。

不要逆向或拼接站点私有接口，不要把认证请求复制到命令行，也不要使用其他账号、缓存、镜像或搜索结果补齐用户无权访问的内容。

## 优先读取底层结构

按以下顺序尝试，前一层成功后不要继续模拟鼠标：

1. 页面 DOM 与可访问的同源 iframe；
2. 页面已经加载的目录、章节属性和代码块文本；
3. Plain Text 区块自己的复制按钮；
4. Plain Text 区块自己的下载按钮。

禁止使用站内搜索框寻找 Plain Text。不要靠截图 OCR 复制长提示词，除非所有结构化方式都不可用，并明确说明准确性限制。

## 手册内页

活动页可能把真实手册放在同源 iframe 中。若检测到类似 `iframe[title="航海手册"]`：

- 优先读取其 `contentDocument`；
- 或把 iframe 的实际 `src` 打开到临时标签页；
- 不重新加载用户原标签页；
- 临时标签页使用后关闭。

## 目录与章节

从目录 DOM 中收集关卡组、章节标题和稳定条目 ID。已知页面常见结构包括：

- 关卡项：`.vc-chapter-item[data-item-id]`；
- 关卡组：`.vc-chapter-group`；
- 标题：`.chapter-title`。

选择篇 / 关卡折叠项时先检查 DOM 是否已经包含其子项。必要时只展开目录，不点击完成、评论或其他写操作。

使用稳定条目 ID 或页面生成的章节 URL 直达章节。可最多 3 个临时标签页并发读取，避免逐次 Computer Use；不要对站点发起无界并发。

## Plain Text DOM

已知新手册常见结构：

```text
区块容器：.block-code
语言标签：.block-code-language
原文节点：code.allow-copy
块 ID：最近的 .vc-doc-item 或 .doc-item
```

只收集语言标签去空白后严格等于 `Plain Text` 的区块，原文读取 `textContent`，不要使用 `innerText` 重排空白。

为每个区块记录最近的上方标题与必要说明。可以按文档顺序查找前面的 `.vc-doc-item` / `.doc-item`；只取足以判断步骤、分支、示例或异常条件的上下文。

## 复制与下载回退

DOM 不能取得原文时：

- 只点击当前 Plain Text 区块的复制图标，然后立即读取本次复制结果；
- 或下载该区块自己的 `.txt` 文件并读取；
- 复制无结果时不要读取或回显用户原有剪贴板；
- 下载文件只放临时目录，提取后清理；
- 逐条核对页面可见开头、结尾与换行。

## 停止条件

出现以下任一情况时停止并报告：

- 用户未登录或没有手册权限；
- CAPTCHA、付费墙或安全拦截；
- 目录无法完整展开；
- Plain Text 原文只能得到截图或被截断；
- 页面结构与已知结构不同，无法可靠识别语言标签；
- 浏览器控制被用户或扩展中断。

不要改用网络搜索、缓存摘要或其他课程替代缺失原文。
