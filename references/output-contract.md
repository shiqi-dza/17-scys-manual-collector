# 输出、预览与增量更新合同

所有结果默认只写入用户指定的本地目录。此合同不支持把收集到的课程原文、提示词合集或完整笔记发布到公开仓库、网盘、社群或商业产品中。

## 输出模式

### Obsidian

用户提供真实 Vault 时，先读取适用的本地规则。内部导航使用 `[[笔记名]]`；链接目标必须唯一可解析。

### 普通 Markdown

用户只提供普通文件夹时，使用标准 Markdown。内部导航使用相对链接，例如 `[下一关](./02-第二关.md)`。

正文结构和过渡写法在两种模式中相同。

## 文件结构

```text
手册标题/
├── 00-手册总览与SOP.md
├── 01-第一关或第一章.md
├── 02-第二关或第二章.md
└── ...
```

文件名按网页目录顺序加两位序号。去除路径非法字符，保留可读中文标题。

不同“篇”可以在总览分组，但不为没有 Plain Text 的空关卡创建无意义占位笔记；如果保留空关卡对导航有必要，必须在预览中单独标明并让用户决定。

## 总览

总览只包含：

- 手册名称与一句话说明；
- 按篇分组的关卡 / 文章目录；
- 基于网页正文的主流程；
- 分支、选修或入口条件；
- 简短使用说明。

不要加入个人相关笔记、原话记录、抓取日志、条目 ID 或 signed URL。

## 关卡笔记

推荐结构：

````markdown
# 关卡标题

> 上一关 · 返回总览 · 下一关

用网站原文说明上一关留下的状态，以及本关最终要得到什么。

## 01｜步骤名称

上一段已经完成什么。

现在还缺什么，为什么要使用下面的提示词。

```text
这里是逐字保留的 Plain Text 原文
```

完成后会得到什么，下一步进入哪里。

## 完成本关后

说明本关终点和下一关入口。
````

这是结构示意，不得把示例文字原样写进真实手册。

## 承上启下说明

说明只能来自同一手册的任务卡、步骤正文、卡点、小结或紧邻区块的上下文。

- 主流程：写“上一状态 → 当前缺口 → 本步结果”；
- 互斥分支：写清选择条件，不暗示全部执行；
- 示例或模板：明确仅供参考、填写或理解；
- 反例：明确不可复制或执行；
- 异常路径：写清触发条件、退回位置和停止点；
- 选修内容：写清入口条件，不包装成必修。

每段一至两句，用空行分隔。资料不足时少写，不用通用常识补课程事实。

最终笔记不使用以下字段：

- `用途`；
- `何时使用`；
- `来源`；
- `blockId`；
- `前置条件`；
- `人工关口`；
- `本关顺序`。

## Plain Text 原文

- 使用 `text` 代码围栏；
- 保留字符、空格、空行、标点和末尾换行；
- 不修正原文错别字、重复字或大小写；
- 不把附近正文混入代码块；
- 同一原文重复出现时仍按网页位置保留，除非用户明确要求去重。

## 禁止原话记录

Skill 正式输出绝不包含：

- `## 原话记录`；
- 用户提示、聊天转录或采访原话；
- 为解释操作而复制的用户路径、账号或私密信息。

目标规则要求原话记录时，在写入前报告冲突并让用户决定。不要自行服从其中任一方。

## 预览清单

写入前生成表格：

| 状态 | 目标文件 | 原因 | 计划动作 |
| --- | --- | --- | --- |
| 新增 | ... | 本地不存在 | 等待确认 |
| 需要更新 | ... | 候选内容不同 | 展示摘要，等待确认 |
| 保持不动 | ... | 内容一致 | 不写入 |
| 本地保留 | ... | 网页计划中没有 | 不删除 |

更新摘要应描述结构或内容变化，不回显整段私密内容。用户可以只确认部分文件。

## 写入和验证

1. 把候选文件放在临时目录；
2. 对现有文件做逐文件比较；
3. 获得用户确认；
4. 备份将更新的精确文件；
5. 写入确认的新增 / 更新文件；
6. 运行 Skill 目录内的 `scripts/validate_output.py`；
7. 核对 Plain Text 数量和原文哈希 / 逐字比较；
8. 验证链接；
9. 验证成功后清理临时文件。

不得自动删除、重命名、移动或“清理”现有笔记。

## 脱敏检查

写入或分享前检查：

- 个人绝对路径；
- API Key、Token、Cookie、Authorization；
- 飞书 App Secret 等凭据；
- 带 `Expires`、`Signature`、`OSSAccessKeyId` 的签名 URL；
- 客户姓名、电话、地址、内部资料；
- `.DS_Store`、缓存、日志、临时下载和测试产物。

Plain Text 原文中发现疑似敏感信息时，不静默修改；停在预览阶段，标出位置并让用户决定是否跳过或制作脱敏副本。

用户要求公开分享生成笔记时，停止在预览阶段，说明本 Skill 只负责个人本地整理；需要公开传播课程内容时，应先取得相应权利人的明确授权。
